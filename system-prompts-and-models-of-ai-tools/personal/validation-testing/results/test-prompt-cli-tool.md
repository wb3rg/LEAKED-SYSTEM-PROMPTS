# Test Prompt: CLI Data Processing Tool

**Scenario 4: Command-Line Data Processing Tool**

Build a powerful CLI tool for data scientists and analysts with these capabilities:
- Multiple data format support (CSV, JSON, Parquet, Excel)
- Data cleaning and transformation operations
- Statistical analysis and summary generation
- Data visualization export (charts, graphs)
- SQL-like query interface for data filtering
- Batch processing for large datasets
- Plugin architecture for custom operations
- Progress tracking for long-running operations
- Export results to various formats
- Configuration file support for reusable workflows

The tool should be cross-platform (Windows, macOS, Linux), handle datasets up to 10GB efficiently, and provide both interactive and batch processing modes. Target users: data scientists, analysts, researchers.
