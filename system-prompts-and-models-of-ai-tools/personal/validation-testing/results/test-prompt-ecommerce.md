# Test Prompt: E-commerce Platform

**Scenario 1: E-commerce Platform Development**

Build a modern e-commerce platform with the following requirements:
- User authentication and profile management
- Product catalog with search and filtering
- Shopping cart and checkout process
- Payment integration (Stripe)
- Order management and tracking
- Admin dashboard for inventory management
- Mobile-responsive design
- Real-time inventory updates
- Email notifications for orders
- Basic analytics and reporting

The platform should handle moderate traffic (1000+ concurrent users) and be production-ready with proper error handling, logging, and security measures.
