# Test Prompt: Mobile Banking App

**Scenario 3: Mobile Banking Application**

Develop a secure mobile banking application with the following capabilities:
- Multi-factor authentication and biometric login
- Account balance and transaction history
- Money transfers (internal and external)
- Bill payment functionality
- Mobile check deposit
- ATM/branch locator with maps
- Push notifications for transactions
- Budgeting and spending analytics
- Customer support chat integration
- Fraud detection and security alerts

The app must meet strict financial regulations (PCI DSS, SOX compliance), handle high transaction volumes, and provide 99.99% uptime with zero data breaches. Target platforms: iOS and Android.
